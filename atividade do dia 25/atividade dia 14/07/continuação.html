Sobre o Projeto

O Projeto Jovem Programador reúne conteúdos para estudantes que estão começando a aprender HTML.

A missão é praticar estrutura, organização e semântica usando tags como header, main, section e foonter.

Aprender HTML é o primeiro passo para criar páginas web.
